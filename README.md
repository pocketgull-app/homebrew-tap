# PocketGull Homebrew Tap

Official Homebrew tap for the **PocketGull** font superfamily.

## Installation

You can install PocketGull fonts using `brew`:

```bash
# Install directly via tap
brew install --cask pocketgull-app/tap/font-pocketgull
```

Or add the tap first:

```bash
brew tap pocketgull-app/tap
brew install --cask font-pocketgull
```

## Included Styles
- **PocketGull Sans**: Regular, Fineliner (Light), Bold, Black, Italic, Bold Italic, Soft, Condensed Bold, Micro
- **PocketGull Slab**: Regular, Bold
- **PocketGull Serif**: Regular, Bold
- **PocketGull Display**: Chiseltip, MarkerRaw, Outline, Inline, Halftone
- **PocketGull Mono**: Regular, Bold, Italic (fixed 600 UPM pitch)
- **PocketGull Variable**: Continuous weight axis (400–900)
